# SGO PVZ — V9 Meteorologia

Interface de visualização operacional para Póvoa de Varzim.

## Novidades
- Categoria **Meteorologia · IPMA MF2**
- Temperatura
- Vento a 10 m
- Rajadas a 10 m
- Humidade relativa
- Precipitação
- FWI
- Apenas uma camada meteorológica ativa de cada vez
- Descoberta automática dos nomes das camadas pelo WMS GetCapabilities do IPMA MF2
- Correção da leitura das observações horárias IPMA na barra superior
- Mantém o design Foggy/map-first da V8

## Fontes
- IPMA API (observações)
- IPMA MF2 / WMS (camadas meteorológicas)
- ANEPC
- SIG Município da Póvoa de Varzim

Nota: as camadas online dependem da disponibilidade dos serviços externos.
